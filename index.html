SuperAgent free search

NO API KEY

General web results from DuckDuckGo, with Wikipedia as an encyclopedia-only fallback. Works with any configured model that supports tools when selected as your Harness web-search provider.

DuckDuckGoWikipedia fallbackv1.1.0
Get install source ↓Inspect source ↗

Free and no-key does not mean every upstream engine is open source: DuckDuckGo is a third-party search service. Public endpoints can block or rate-limit traffic. Wikipedia fallback is not a replacement for general web search. Queries are sent to the services used; results remain untrusted.

COPY · PASTE · INSTALL

Install from a pinned source

This source points to the plugin folder at a specific release commit, not the catalog webpage. Review the source before installing code into your profile.

  1. Open Plugins → Add plugin in DeepSeek Harness.
  2. Paste the source above into the source input, then install and enable the bundle. The change applies to the current profile.
  3. Open Settings → Web search and choose SuperAgent free search as the search provider.
  4. Start a new chat with any model that supports tools and ask it to search. Your model API usage is separate; this plugin requires no search API key.
Prefer the CLI?

Only if you already have the dsh CLI available. The Desktop app does not necessarily put it on your PATH. Replace desktop with your target profile when needed.

Install from a local checkout

Clone the repository, then use Plugins → Add plugin with the absolute path to its websearch-plugin folder. Keep that folder in place: local directory installs may link to the source.

git clone https://github.com/AgentsLabs/SuperAgent-Harness-Plugins.git

Then select SuperAgent free search in Settings → Web search.

OPTIONAL · DISCOVER PLUGINS

Add the SuperAgent plugin index

Browse our catalog inside Harness using its optional Custom plugin indexes feature. The website is not a one-click installer: you confirm installation inside Harness.

  1. In Plugins, enable the optional Custom plugin indexes feature if it is available in your DSH version.
  2. Open Plugins → Discover → Add index source and paste the index URL above. For an existing setup, use the index menu’s Manage index sources… option.
  3. Find SuperAgent free search in Discover, inspect the details, and install it.
  4. Select SuperAgent free search in Settings → Web search. If your version lacks Discover, use the source installation above.
